# 🌱 SOLO LIMPO

Jogo de quiz educativo sobre **poluição do solo**, feito para um trabalho de
biologia do ensino médio.

A cada resposta certa, o solo da tela vai se recuperando: começa seco e poluído
e termina verde e cheio de vida. São **12 perguntas** divididas em **3 fases**
("A Origem do Problema", "Os Impactos" e "A Solução"), com pontuação, sequência
de acertos (combo 🔥), estrelas por fase e animações.

## ▶️ Como jogar

Abra o arquivo `index.html` em qualquer navegador moderno (celular ou computador).
Não há instalação nem dependências.

## 🛠️ Tecnologia

- HTML, CSS e JavaScript puro, **tudo em um único `index.html`**.
- Sem frameworks, sem build, sem recursos externos.
- Sons gerados via Web Audio API (com botão para ligar/desligar).
- Totalmente responsivo.

## 🚀 Deploy no Vercel

1. Acesse [vercel.com/new](https://vercel.com/new).
2. Importe este repositório (`solo-limpo`).
3. Não é preciso configurar nada — é um site estático. Clique em **Deploy**.

O `index.html` está na raiz do projeto, que é o necessário para a hospedagem estática.
