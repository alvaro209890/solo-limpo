# 🌱 SOLO LIMPO — Edição Premium

Jogo de quiz educativo sobre **poluição do solo**, desenvolvido para um trabalho de biologia do ensino médio. O projeto combina aprendizado lúdico com uma interface visual dinâmica que reage às ações do jogador.

A cada resposta certa, o solo da tela se recupera visualmente: começando seco e poluído e terminando verde, florido e cheio de vida.

## ✨ Novidades e Melhorias (v2.0)

- **📱 Responsividade Total:** Interface otimizada para dispositivos móveis, com elementos que se ajustam automaticamente para garantir a melhor jogabilidade em qualquer tela.
- **🌅 Ciclo de Iluminação Dinâmico:** O fundo do jogo transita entre Dia, Entardecer e Noite conforme o progresso nas fases, aumentando a imersão.
- **🐛 Minhoco Interativo:** O mascote do jogo agora possui animações complexas (GSAP) e reage emocionalmente aos seus acertos e erros, além de dar dicas biológicas.
- **💡 Fatos Curiosos:** Inclusão de curiosidades científicas ("Você Sabia?") após as respostas para reforçar o aprendizado pedagógico.
- **🎨 Visual Polido:** Uso de gradientes modernos, sombras suaves e animações fluidas com GSAP.

## 🎮 Estrutura do Jogo

São **12 perguntas** fundamentadas em conteúdos de biologia, divididas em **3 fases** temáticas:
1. **🚜 A Origem do Problema:** Causas e fontes de poluição.
2. **🏜️ Os Impactos:** Consequências para o ecossistema e saúde humana.
3. **🌱 A Solução:** Práticas de preservação, reciclagem e recuperação.

## ▶️ Como jogar

Abra o arquivo `index.html` em qualquer navegador moderno. Não há necessidade de instalação de dependências ou servidores.

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3:** Estrutura e estilização moderna com variáveis CSS.
- **JavaScript Puro (Vanilla):** Lógica do jogo e manipulação de estado.
- **GSAP (GreenSock):** Animações de alto desempenho para o mascote e transições de tela.
- **Web Audio API:** Geração de efeitos sonoros dinâmicos sem arquivos externos.
- **Canvas Confetti:** Efeitos de celebração ao concluir objetivos.

## 🚀 Como fazer o Deploy (Vercel/GitHub Pages)

O projeto é 100% estático, facilitando a hospedagem:
1. Suba os arquivos para um repositório no GitHub.
2. Conecte ao **Vercel** ou ative o **GitHub Pages** nas configurações do repositório.
3. O jogo estará online instantaneamente.
